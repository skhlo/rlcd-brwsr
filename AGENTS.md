# RLCD-brwsr

Read `docs/RLCD-BRWSR.md` before implementing v0.1 or changing its architecture. It owns the agreed scope, safety envelope, reference pins and verification plan.

## Delivery

Use direct repository checks and normal Git/GitHub delivery for this repository.
Do not run no-mistakes here; this is the repository-specific exception to the
shared delivery workflow. Before an authorized push, run the relevant tests,
type checks and formatting checks, review the changes, and report limitations.
Publication still requires user authorization; never merge a PR.
